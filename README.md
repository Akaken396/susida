# 寿司打 自動入力ツール

画面に表示されるローマ字（例: `saikousinkiroku`）を OCR で読み取り、自動でキー入力します。

寿司打は canvas に描画されていて文字を直接取得できないので、画面キャプチャ → 白い文字だけ抽出 → Tesseract OCR → キー送信、という流れで動きます。
入力済みの文字は灰色になるため OCR で無視され、**まだ打っていない文字だけ**が読まれます。読み間違えても次のループで残りを打ち直すので、自然に回復します。

## 必要なもの

1. **Python 3.9 以上**
2. **Tesseract OCR**
   - Windows: <https://github.com/UB-Mannheim/tesseract/wiki> からインストール（既定の `C:\Program Files\Tesseract-OCR\` なら自動で見つけます）
   - macOS: `brew install tesseract`
   - Linux: `sudo apt install tesseract-ocr`
3. Python ライブラリ

```bash
pip install -r requirements.txt
```

> macOS では「システム設定 → プライバシーとセキュリティ」で、ターミナルに **画面収録** と **アクセシビリティ（入力監視）** の許可が必要です。

## 使い方

1. ブラウザで寿司打を開き、ゲームを開始できる状態にする（画面の位置は動かさない）。
2. 読み取り範囲を指定する。全画面が暗くなるので、**ローマ字の行**（白い英字の部分）を少し余裕をもってドラッグで囲みます。日本語の行は含めないでください。

```bash
python sushida_auto.py --calibrate
```

3. 読み取りを確認する（任意）。ローマ字が出ている状態で実行し、正しく読めるか確認します。`debug_raw.png` / `debug_processed.png` が保存されます。

```bash
python sushida_auto.py --test
```

4. 実行する。

```bash
python sushida_auto.py
```

5. 寿司打の画面をクリックしてフォーカスを合わせ、ゲームを開始して **F9** を押すと自動入力が始まります。

| キー | 動作 |
| --- | --- |
| F9 | 開始 / 一時停止 |
| F10 | 終了 |

## 設定 (`config.json`)

範囲指定をすると `config.json` が作られます。必要なら編集してください。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| `region` | – | 読み取り範囲（物理ピクセル） |
| `tesseract_cmd` | `null` | `tesseract` 実行ファイルのパス。PATH にない場合に指定 |
| `threshold` | `200` | 白文字とみなす明るさ。読めないときは 170〜220 で調整 |
| `scale` | `3` | OCR 前の拡大倍率 |
| `key_interval` | `0.01` | 1 文字ごとの入力間隔（秒）。ミスが多いときは大きく |
| `poll_interval` | `0.05` | 画面を読む間隔（秒） |
| `retype_after` | `0.6` | 同じ文字列を再入力するまでの待ち時間（秒） |

## うまく動かないとき

- **何も読めない / 変な文字になる**: `--test` で `debug_processed.png` を見て、白地に黒い英字だけが写っているか確認。写っていなければ `threshold` を下げるか、範囲を指定し直す。
- **画面の拡大率（125% など）でずれる**: Windows では DPI 対応を有効にしていますが、ずれる場合はブラウザのズームを 100% にして範囲を指定し直す。
- **マルチモニター**: 範囲指定はメイン画面のみ対応です。寿司打をメイン画面に置いてください。
- **ブラウザやウィンドウを動かした**: `--calibrate` で範囲を指定し直す。

## 注意

個人の練習・検証用です。自動入力で出したスコアをオンラインランキングに登録するのは控えてください。
